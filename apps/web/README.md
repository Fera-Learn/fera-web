# Fera Web

Fera Web is the public product and marketing site for Fera. It explains the learning platform, introduces available courses, and creates clear paths into Academy for structured study and practice.

## Product Surfaces

- Landing pages for the Fera product story.
- Course and feature previews for prospective learners.
- Product navigation for questions, exams, and Academy entry points.
- Marketing content that connects course structure with practice and exam readiness.

## Platform Role

Web is the first-touch product surface. It positions Fera for learners before they enter Academy and reuses shared UI components to keep the product experience consistent.

## Development

```sh
pnpm --filter web dev
pnpm --filter web lint
pnpm --filter web build
```
