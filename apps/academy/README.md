# Fera Academy

Fera Academy is the learning application for Fera. It gives physics and mathematics learners a structured place to move from course explanations into practice questions, exam papers, equation references, and flashcards.

## Product Surfaces

- Course outlines and topic pages for structured study.
- Topic-linked question practice with answers and difficulty filters.
- Exam paper sets for course-level preparation.
- Equation sheets for compact reference and print workflows.
- Flashcards for recall across questions and equations.

## Platform Role

Academy is the product workspace learners use after discovering Fera through the public site. It depends on shared documentation and UI packages for navigation, rendering, layout, and interface primitives.
